# @kewen/dsh-sidebar-plus

**DSH 侧栏 Plus（macOS 渐进式全屏三态工作台）**

为 DeepSeek Harness (DSH) macOS 桌面端提供 Codex 级三层渐进式工作台体验，彻底解决官方在 macOS 下全屏时粗暴遮挡左侧导航栏的缺陷。

---

## 核心特性

- **三层渐进式视界（Codex 体验）**：
  - **态 1（分栏伴生）**：左侧栏 + 中间聊天 + 右侧工具（白板/浏览器/代码/监控）；
  - **态 2（宽幅工作台）**：点击右上角全屏，中间聊天区平滑折叠，右侧面板占据中央主视界，**左侧导航栏完好保留、随时可用**；
  - **态 3（极致沉浸）**：按 Mac 原生快捷键 `⌘B` 收起左侧栏，直接达成 100% 满屏无干扰大画布/浏览器。
- **全局通用适配**：
  - 自动对右侧栏所有 Tab 通用生效（DSH 白板 Plus、内置浏览器、文件 Diff / 代码审查、自动化任务等）。
- **智能安全避让**：
  - 左侧栏展开时，自动消除顶栏多余的 88px 空隙，标题紧凑靠左；
  - 左侧栏折叠时（100% 全屏），自动恢复 88px 避让，保护 macOS 红黄绿窗口控制按钮不被遮盖。
- **极简架构，零性能损耗**：
  - 纯 `ResizeObserver` 动态跟踪，零臃肿依赖，安全沙箱隔离。
